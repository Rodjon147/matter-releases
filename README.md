# Matter

Matter is a desktop app for Markdown notes. Notes, attachments and settings stay in local workspace folders. No account is required, and editing works offline.

## Download

[Download for Windows x64](https://github.com/Rodjon147/matter-releases/releases/latest)

The installer is currently unsigned. Windows SmartScreen may display a warning.

## Features

- Rich text editing with a Markdown source view.
- A customizable home page with folder and collection widgets.
- Folders, tabs, search, note links and backlinks.
- Trash with search, restore and permanent deletion.
- Attachments, resizable images, text wrapping, autosave, and light and dark themes.

## Updates

Installed Windows versions download updates in the background. Installation starts after **Restart & Update** is selected and pending edits have been saved. Closing Matter normally does not install an update.

Updates preserve the workspace, notes, attachments and settings. Automatic updates are available for NSIS installations; development and unpacked builds use manual updates.
