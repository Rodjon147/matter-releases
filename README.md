# Matter

Matter is a desktop app for Markdown notes and visual canvases. Notes, drawings, attachments and settings stay in local workspace folders. No account is required, and editing works offline.

## Download

[Download Matter 0.4.0 for Windows x64](https://github.com/Rodjon147/matter-releases/releases/tag/v0.4.0)

Choose **Matter-Setup-0.4.0.exe**. The installer is unsigned, as in previous releases; Windows SmartScreen may display a warning. The release includes a manifest and SHA-256 checksums.

## New in 0.4.0

- Create Excalidraw canvases alongside notes. Rename, move, drag, open in tabs, send to Trash and restore them using the same file tree.
- Draw with shapes, arrows, text, images, freehand tools, frames, groups and a local object library. The editor follows Matter's themes and supports English and Russian.
- Embed a linked canvas in a note with `/Canvas`, `/Холст` or drag and drop. Choose an existing canvas or create one directly from the insertion dialog.
- Pan and zoom inside a widget, select **Open canvas** to edit the source, then return to the original note. Multiple widgets stay linked to the same drawing; removing a widget keeps its source file.
- Import `.excalidraw`, export PNG/SVG/Excalidraw and copy an image. Fonts are bundled locally and embedded in exported SVG files.

## Features

- Rich text editing with a Markdown source view and optional YAML note properties.
- A live Contents outline with heading navigation and collapsible branches.
- A customizable Home page with a visual block editor, note collections, sections, recent notes, text, quick links, images, greetings and dividers.
- Folders, tabs, search, note links, visual canvases and linked note widgets.
- Trash with search, restore and permanent deletion.
- Attachments, resizable images, text wrapping, autosave, contextual table controls and undo/redo.
- Dark, Light and System themes, with English and Russian interface languages.

## Updates

Installed Windows versions download updates in the background. Use **Settings → General → Check for Updates**. Installation starts after **Restart & Update** is selected and pending edits have been saved. Closing Matter normally does not install an update.

Updates preserve workspace files and settings. Automatic updates are available for NSIS installations; development and unpacked builds use manual updates.
