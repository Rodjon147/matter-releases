# Matter 0.2.0

- Redesigned Collection widgets around inline editing: creation immediately focuses the name, Enter/blur saves, Escape cancels and an empty title defaults to Collection. Notes can be dragged from Sidebar or added through the shared resource picker.
- Added in-widget pointer reordering, insertion previews, keyboard reorder shortcuts and Open / Remove from Collection context actions. Duplicate references are rejected; removing a reference never deletes its file.
- Folder widgets now show live folder contents through the existing workspace watcher. Slash creation and Change Folder use the shared picker; dropping a Sidebar folder into Homepage inserts its widget at the previewed block boundary without opening a modal.
- Added consistent resource drag overlays, note row previews, Folder ghost previews, cancellation and explicit target priorities. Sidebar moves keep their original filesystem behavior; drops into widgets only create references.
- Folder drops can join an existing widget row, including inserting a third card alongside two others. The preview and drop use document geometry without interference from the placeholder.
- Completed folder drops consume their gesture once and discard their temporary preview. Delayed move/end callbacks cannot revive a ghost card or create an extra widget; previews also clear when the document changes.
- Removed widget options menus and note counters. Headings stay available, including for older configurations with hidden-title settings; collection names remain editable inline.
- Moved Add notes to a compact heading button that fades in on card hover and fades out on exit, without reserving list space or changing the card height. Keyboard focus also reveals it.
- Added a removal zone that appears only while dragging a note from its source collection. A drop removes its reference, keeps the note file and persists the remaining order; Escape cancels.
- Sidebar additions and collection reordering use the same compact note preview, without the accent stripe or trailing plus. During reordering the card replaces its source row and the removal zone stays in place. Floating note labels disappear over collection cards and reappear outside them.
- Dragging a note over an empty collection replaces its icon and instructions with the note preview; leaving or cancelling restores them.
- Moving widgets within a row no longer leaves a blinking caret between cards. Normal text and inline collection-title editing retain their caret.
- Replaced the old modal widget editors with one resource picker for notes and folders, including search, location details, keyboard navigation, selections, folder browsing and virtualization.
- Notes remain in their original locations. Collection references follow renames and moves; missing notes can be removed from the collection without deleting other notes.
- Added grid-based pointer resizing to Folder and Collection widgets: 12 columns horizontally and 16-pixel steps vertically, with room for at least three compact cards per row.
- Added content-aware size limits and automatic height growth. Long names use ellipsis and full-path tooltips. Existing undersized Folder widgets also grow to fit their contents.
- Resize using the edges or corner; Escape cancels the active resize.
- Serialized widget edits, retained failed operations for Retry, and included inline drafts in the close/workspace-switch flush. Improved identity reconciliation for rapid external folder renames following in-app moves.
- Preserved rename identities across separate watcher notification batches, so collection references also follow external renames during heavy filesystem activity. File identities include birth time to distinguish newly created files when an inode is reused.
- Widget names, selections, order, sizes and display options persist across app restarts.

Windows x64 NSIS release. Existing installations receive this version through the stable update channel; new installations use [Matter-Setup-0.2.0.exe](https://github.com/Rodjon147/matter-releases/releases/download/v0.2.0/Matter-Setup-0.2.0.exe).
