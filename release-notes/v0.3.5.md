# Matter 0.3.5 — Contents, refreshed settings and Russian

This stable Windows x64 update includes all improvements since Matter 0.3.0. Your existing workspace stays local and remains compatible.

## Navigate long notes

- The new **Contents** panel replaces Page details with an outline of headings H1–H6. Click a heading to jump to its section, collapse nested branches and follow your current section while scrolling.
- Contents updates as you write, undo, redo or edit the file externally. Duplicate headings keep separate destinations; code blocks and YAML are excluded. Navigation works in both the visual editor and Markdown source.
- **Settings → Editor → Show contents by default** controls automatic display. You can also hide or reopen the panel manually.
- **Expand all folders / Collapse all folders** reveals the current note in the file tree. **Ctrl + click** opens only the current note’s parent folders and closes unrelated branches.

## Refreshed settings and two languages

- Settings has a clearer two-column layout, larger labels, grouped options and a fixed automatic-save footer.
- Choose **Dark**, **Light** or **System** using preview cards. Typography, density and line width use segmented controls; font size has minus/plus controls. All Boolean editor settings use the same switches.
- **Settings → General → Application language** switches between **English** and **Русский** immediately. The choice persists across restarts and workspaces, including the welcome screen and native file dialogs.
- Menus, command and block search, tooltips, properties, widgets, errors and update messages are localized. Dates, automatic greetings and word counts follow the selected language. Note text, file names, YAML keys and user-authored Home content are not rewritten.

## More editor improvements

- Optional YAML **Properties** support imported Obsidian metadata, tags, editable field names and typed values: text, lists, numbers, checkboxes, dates, date/time, time and dropdowns.
- Reorder dropdown options by dragging or keyboard, preserve unnamed fields, and choose whether Properties opens expanded. New date/time values use the device’s local clock. Undo/redo and Markdown round trips preserve the data.
- Contextual table controls insert, move and delete rows and columns, with drag previews, keyboard menus and undo/redo.
- The slash menu keeps the selected block in view during keyboard navigation. File-tree collapse also clears its selection and focus.

## Download and update

Download **Matter-Setup-0.3.5.exe** to install Matter on Windows x64. Existing NSIS installations can use **Settings → General → Check for Updates**; your notes are saved before restarting. Unpacked and portable copies do not update automatically.

The installer is unsigned, as in previous releases. SHA-256 checksums and the release manifest are included; Windows may show a SmartScreen prompt.
