# Matter 0.2.5

- Collapse the sidebar into a compact rail while keeping New note, Search, Home, Trash, Settings and Workspace available. Tooltips support both pointer hover and keyboard focus.
- Keep New note beside Files in the expanded sidebar and at the top of the compact rail. The original search field styling is preserved.
- Find Trash directly below Home in both sidebar states. Its window opens beside the sidebar and follows resizing or collapse without replacing the current note.
- Use a shared bottom row for Workspace and Settings, with the same background as the sidebar. A folder represents Workspace, and navigation icons stay consistent between states.
- Improve secondary text contrast and interface typography. On narrower windows, Page details opens over the document and wide tables scroll within their own area.
- Keep an unfinished note name when Windows reports an external folder rename across consecutive polling events.

Existing workspaces, Markdown files, attachments, settings and application workflows remain compatible. No data migration is required.

Windows x64 NSIS release. Installed Windows versions receive updates through the stable update channel, preserving workspaces, notes, attachments and settings.
