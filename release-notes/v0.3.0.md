# Matter 0.3.0 — Build your own Home

Home is now a dedicated, customizable page with a visual block editor. Arrange the notes, sections and shortcuts you use most without editing Markdown or writing code.

## A new Home editor

- Open **Customize Home** and drag blocks from the right panel onto the page. A placement preview shows where each block will land.
- Build with **Greeting, Divider, Text, Section card, MOC, Recent notes, Quick links and Image** blocks. Move, remove and add the greeting and divider just like any other block.
- Use **MOC (Map of Contents)** to collect notes in your own order, with an optional heading, list or card display and optional note icons. MOC replaces Folder and Collection widgets on Home.
- Drag a block from anywhere on its surface. Editing previews are dimmed and show a clear move hint; links and other block actions become available in viewing mode.
- Keep adding blocks beside existing blocks or on a new row. Dropping onto an occupied position moves its neighbor to the nearest available position. Position controls disable choices that would overlap another block.
- Choose full, half or third width, align headings, and position blocks within a row. Greeting alignment applies to all greeting text. Optional block backgrounds and borders can be hidden; Section cards keep their card styling.
- Set an image's displayed width in **Size**, preserve its proportions, or reset it to its default fitted size.
- Delete a block using its properties or the deletion area that appears while dragging. Removing a Home block does not delete its notes.
- **Undo/Redo**, a recoverable local draft and fixed **Done/Cancel** buttons make it easy to experiment. Save errors offer a retry.

## Settings and fixes

- A larger Settings window with a compact header provides more room for controls.
- Version information, the changelog and update checking now live together in **General**. The Startup behavior option has been removed.
- Fix the unwanted initial selection and action toolbar on the first note widget.
- Support light and dark themes, narrow windows and the existing collapsible sidebar throughout the new Home editor.

## Updating from an earlier release

The existing Home is backed up before it is migrated to the new block format. Ordinary Markdown notes, their editor, attachments and workspace files remain available. Home links follow note and folder renames.

This stable release includes the changes tested in the local 0.2.6 and 0.3.0 preview builds. Those previews are not published as separate releases; the public update goes directly from **0.2.5 to 0.3.0**.

Windows x64 NSIS installer. Installed Windows versions receive 0.3.0 through the stable update channel. The installer is unsigned, as in previous releases; Windows may show a SmartScreen warning.
