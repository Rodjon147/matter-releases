# Matter 0.4.0 — холсты

Обновление для Windows x64 с холстами и связанными виджетами заметок. Существующие рабочие папки, заметки и настройки остаются совместимыми.

Холсты теперь живут рядом с заметками в файловом дереве. Кнопка «Создать холст» находится между созданием папки и раскрытием дерева. Холст можно переименовать, перенести мышью или через меню, открыть в отдельной вкладке, отправить в корзину и восстановить.

Редактор на основе Excalidraw поддерживает фигуры, стрелки и их привязки, текст, изображения, свободное рисование, ластик, рамки, группы, слои, библиотеку объектов, Undo/Redo и масштабирование. Оформление адаптировано к темам и акценту Matter. Объект можно связать с локальной заметкой.

В заметку холст вставляется через `/Холст`, `/Canvas`, меню блоков или перетаскиванием файла из sidebar. Можно выбрать существующий холст либо создать новый с нужным именем и расположением. Виджет изменяет размер и положение как другие виджеты. Нажмите «Просмотр холста» для панорамирования и масштаба; Escape возвращает управление заметке.

Постоянная кнопка «Открыть холст» ведёт прямо к редактированию источника. «Вернуться к заметке» возвращает к исходной вставке и её позиции. Один холст можно вставить несколько раз: все виджеты показывают одну сцену, а их размеры и видовые области независимы.

Переименование и перенос сохраняют связи. Удаление виджета убирает только вставку; исходный файл остаётся. Если файл в корзине, виджет предлагает восстановление. Создание и удаление виджета отменяются отдельными действиями Undo.

Рисунки хранятся в открытом формате `.excalidraw`. Есть импорт, экспорт PNG/SVG/Excalidraw и копирование изображения. Шрифты включены локально; SVG содержит встроенные шрифты. Работа не требует аккаунта или подключения к сети. Русский интерфейс включает дополнительные переводы команд и подсказок, отсутствовавшие в исходной поставке Excalidraw.

## Установка и обновление

Скачайте **Matter-Setup-0.4.0.exe** для установки на Windows x64. Установленные через NSIS версии могут обновиться через **Настройки → Общие → Проверить обновления**. Перед командой **Перезапустить и обновить** Matter сохраняет ожидающие изменения. Копии `win-unpacked` не устанавливают обновления автоматически.

Установщик неподписан, как и в предыдущих выпусках. Windows может показать предупреждение SmartScreen. В релиз включены манифест и контрольные суммы SHA-256; файлы `latest.yml` и blockmap используются для проверки и загрузки обновления.
